Deploy POS dan SSO ke VPS

Ya, langkah berikutnya memang database. Tapi urutannya POS dulu, baru SSO. POS hanya butuh PostgreSQL dan login booking yang sudah jalan, sedangkan SSO butuh LDAP tambahan di VPS 1 GB ini dan mengubah cara login booking.

Kerjakan pertama: password postgres

Repo final-project publik, dan log yang sudah ter-push menulis bahwa password postgres di VPS masih password lama yang bocor. Kalau belum diganti, ganti sekarang di terminal VPS, lalu cek RAM dan proses yang sedang jalan.

sudo -u postgres psql -c "\password postgres"
free -m
pm2 list

1. Siapkan database POS

Terminal VPS

Blok ini membuat pos_db, folder aplikasi, dan file .env POS. Password dibuat acak dan langsung masuk ke file, jadi tidak perlu kamu ketik. JWT_ACCESS_SECRET dan INTERNAL_API_KEY sengaja sama dengan booking supaya akun dan integrasinya nyambung.

sudo mkdir -p /var/www/pos/backend /var/www/pos/frontend/dist /var/www/sso/backend
sudo chown -R "$USER": /var/www/pos /var/www/sso

POS_PW=$(openssl rand -hex 24)
sudo -u postgres psql -c "CREATE ROLE pos_user LOGIN PASSWORD '$POS_PW';"
sudo -u postgres psql -c "CREATE DATABASE pos_db OWNER pos_user;"

BOOKING_ENV=/var/www/booking/backend/.env
grep -q '^INTERNAL_API_KEY=.' "$BOOKING_ENV" || printf '\nINTERNAL_API_KEY=%s\n' "$(openssl rand -hex 32)" >> "$BOOKING_ENV"
JWT=$(grep '^JWT_ACCESS_SECRET=' "$BOOKING_ENV" | cut -d= -f2-)
KEY=$(grep '^INTERNAL_API_KEY=' "$BOOKING_ENV" | cut -d= -f2-)

umask 077
cat > /var/www/pos/backend/.env <<EOF
NODE_ENV=production
PORT=5001
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=pos_db
DB_USERNAME=pos_user
DB_PASSWORD=$POS_PW
DB_SSL=false
JWT_ACCESS_SECRET=$JWT
BOOKING_API_URL=http://127.0.0.1:5000/api/v1
INTERNAL_API_KEY=$KEY
BOOKING_TIMEOUT_MS=3000
CORS_ORIGIN=https://pos.pratitis.net
SSO_AUDIENCE=pos-api
EOF
umask 022
pm2 restart booking-api --update-env
pm2 list

2. Pasang Nginx dan HTTPS

WinSCP, lalu terminal VPS

Di WinSCP, upload dua file ini ke /home/pratitis-yohanes/: pos-pro/deploy/nginx/pos.pratitis.net.conf dan sso-pro/deploy/nginx/sso.pratitis.net.conf. Setelah itu jalankan:

cd ~
sudo cp pos.pratitis.net.conf sso.pratitis.net.conf /etc/nginx/sites-available/
sudo ln -s ../sites-available/pos.pratitis.net.conf /etc/nginx/sites-enabled/
sudo ln -s ../sites-available/sso.pratitis.net.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d pos.pratitis.net -d sso.pratitis.net --redirect
ls /etc/nginx/sites-available/

Blokir route internal booking

Jangan timpa file booking di server dengan file dari repo, karena file di server sudah berisi pengaturan HTTPS dari certbot. Buka file booking di sites-available dengan sudo nano, lalu tambahkan blok ini di dalam server yang punya listen 443 ssl, sebelum location /api/:

location /api/v1/internal/ {
    return 404;
}
sudo nginx -t && sudo systemctl reload nginx

5. Pasang LDAP dan database SSO

WinSCP, lalu terminal VPS

Upload folder sso-pro/ldap/ldif ke /home/pratitis-yohanes/ldif, lalu jalankan blok ini. Akses LDAP dibatasi ke server sendiri. Password admin LDAP disimpan di ~/.ldap-admin, dan password akun layanan service-secret dari repo publik langsung diganti.

LDAP_ADMIN=$(openssl rand -hex 24)
SVC_PW=$(openssl rand -hex 24)
SSO_PW=$(openssl rand -hex 24)
( umask 077; echo "$LDAP_ADMIN" > ~/.ldap-admin )

sudo debconf-set-selections <<EOF
slapd slapd/password1 password $LDAP_ADMIN
slapd slapd/password2 password $LDAP_ADMIN
slapd slapd/domain string kandang.local
slapd shared/organization string KandangMart
slapd slapd/no_configuration boolean false
EOF
sudo DEBIAN_FRONTEND=noninteractive apt-get install -y slapd ldap-utils
sudo sed -i 's|^SLAPD_SERVICES=.*|SLAPD_SERVICES="ldap://127.0.0.1:389/ ldapi:///"|' /etc/default/slapd
sudo systemctl restart slapd

ADMIN_DN="cn=admin,dc=kandang,dc=local"
ldapadd -x -H ldap://127.0.0.1 -D "$ADMIN_DN" -w "$LDAP_ADMIN" -f ~/ldif/bootstrap.ldif
sudo ldapmodify -Y EXTERNAL -H ldapi:/// -f ~/ldif/acl.ldif
ldappasswd -x -H ldap://127.0.0.1 -D "$ADMIN_DN" -w "$LDAP_ADMIN" -s "$SVC_PW" "cn=auth-service,ou=services,dc=kandang,dc=local"

sudo -u postgres psql -c "CREATE ROLE sso_user LOGIN PASSWORD '$SSO_PW';"
sudo -u postgres psql -c "CREATE DATABASE sso_db OWNER sso_user;"

umask 077
cat > /var/www/sso/backend/.env <<EOF
NODE_ENV=production
HOST=127.0.0.1
PORT=5002
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=sso_db
DB_USERNAME=sso_user
DB_PASSWORD=$SSO_PW
DB_SSL=false
LDAP_URL=ldap://127.0.0.1:389
LDAP_BASE_DN=dc=kandang,dc=local
LDAP_BIND_DN=cn=auth-service,ou=services,dc=kandang,dc=local
LDAP_BIND_PASSWORD=$SVC_PW
JWT_PRIVATE_KEY_PATH=./keys/private.pem
JWT_KEY_ID=kid-2026-10
TOKEN_ISSUER=kandangid
PUBLIC_URL=https://sso.pratitis.net
USER_AUDIENCE=booking-api,pos-api
COOKIE_SECURE=true
MFA_ENFORCE_ADMIN=false
MFA_ENCRYPTION_KEY=$(openssl rand -hex 32)
MFA_ISSUER=KandangMart
EOF
umask 022

Akun demo ikut masuk ke LDAP dengan password demo yang memang sudah ada di repo, dan id-nya sama dengan seeder booking. Kalau akun di production booking berbeda, uid di bootstrap.ldif perlu disamakan dulu dengan id di booking_db.

6. Deploy auth-service

GitHub, lalu terminal VPS

Di repo sso-pro, buka Actions, pilih CI/CD, lalu Run workflow. Deploy pertama bisa gagal di health check karena kunci tanda tangan belum ada. Itu wajar selama kode sudah terunggah. Buat kuncinya, lalu daftarkan aplikasi:

cd /var/www/sso/backend
npm run keys:generate
pm2 startOrReload ecosystem.config.js --update-env
pm2 save
npm run client:create -- booking-api "Booking API" "auth:validate users:read users:write"
npm run client:web -- booking-web "Booking" "https://booking.pratitis.net"
npm run client:web -- pos-web "POS" "https://pos.pratitis.net"
curl -s http://127.0.0.1:5002/api/v1/health

Simpan secret yang muncul dari client:create, karena dibutuhkan di tahap berikutnya. Jangan tempel secret itu ke chat.

7. Sambungkan booking dan POS ke SSO

Terminal VPS

Ganti ISI_SECRET_CLIENT_CREATE dengan secret dari tahap 6.

cat >> /var/www/booking/backend/.env <<'EOF'

AUTH_PROVIDER=sso
AUTH_SERVICE_URL=http://127.0.0.1:5002
AUTH_CLIENT_ID=booking-api
AUTH_CLIENT_SECRET=ISI_SECRET_CLIENT_CREATE
SSO_JWKS_URL=http://127.0.0.1:5002/.well-known/jwks.json
SSO_ISSUER=https://sso.pratitis.net
EOF
cat >> /var/www/pos/backend/.env <<'EOF'
SSO_JWKS_URL=http://127.0.0.1:5002/.well-known/jwks.json
SSO_ISSUER=https://sso.pratitis.net
EOF
pm2 restart booking-api pos-api --update-env
pm2 list
